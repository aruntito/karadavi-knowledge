# Public Indexes

This directory is reserved for generated, versioned indexes that help consumers locate published entity records.

## Rules

- Indexes must be reproducible from approved records.
- Do not place private drafts, reviewer notes, credentials, or operational database exports here.
- Keep index files reasonably sized; shard them by trail, type, or prefix as needed.
- Include a generator/version and the source revision where practical.
- Validate every referenced entity ID.
- Never allow index generation to turn unreviewed proposals into public records.

No index format has been adopted yet. Choose one only after the schema, file layout, expected query patterns, and website caching strategy are reviewed.
